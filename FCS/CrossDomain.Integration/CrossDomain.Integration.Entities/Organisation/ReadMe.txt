The organisation classes were generated from the corporate schema using Xsd2code.  Please follow the steps below to regenerate the classes from a new version of the schema:

1) Replace the existing schema file with the new version.
2) Access the properties of the file and set the build action to 'Embedded Resource'.
3) Download Xsd2Code
4) Right click on the schema Xsd file and select RunXsd2code
5) Ensure GenerateXmlAttributes and GenerateOrderXmlAttributes are set to true
6) Click 'Generate'
